# 02 - 项目结构

本仓库是单仓多工程（monorepo）：根目录只放**工程规范与 Git 钩子**，`admin/` 是前端工程，`api/` 是后端工程。

## 仓库根目录树

```
ly-admin/
├─ admin/                       # 前端工程（Vue3 + Vite 8 + Element Plus）
├─ api/                         # 后端工程（Express 5 + TS + Sequelize）
│  ├─ web/                      # 前端构建产物映射目录（同源部署时由后端托管，产物不入库）
│  ├─ uploads/                  # 上传文件目录（内容不入库）
│  └─ logs/                     # 日志文件目录
├─ .husky/                      # Git Hooks（pre-commit / commit-msg / pre-push）
├─ scripts/                     # 根脚本（如依赖基线守卫 deps-guard.mjs）
├─ package.json                 # 根脚本：lint / format / commit / dev（并行启动）
├─ eslint.config.mjs            # ESLint flat config（覆盖 admin + api）
├─ .prettierrc.json             # Prettier 规则
├─ .stylelintrc.json            # Stylelint 规则
├─ .stylelintignore
├─ commitlint.config.cjs        # 约定式提交校验规则
├─ .czrc                       # cz-git 交互式提交配置
├─ lint-staged.config.cjs       # 暂存区分派 lint / format
├─ .npmrc                       # npmmirror 镜像源
├─ package-lock.json            # 根锁定文件（必须提交入库）
├─ LICENSE                      # MIT
└─ README.md
```

## 前端 `admin/` 关键目录

```
admin/
├─ auto-imports.d.ts            # 自动导入 API 类型声明（生成于根，提交入库，勿手改）
├─ components.d.ts              # 自动注册组件类型声明（生成于根，提交入库，勿手改）
├─ package.json
├─ package-lock.json
├─ vite.config.ts               # Vite 配置（含自动导入、Tailwind v4 插件、压缩、vendor 拆分）
├─ tsconfig.json                # 浏览器端 TS 配置
├─ tsconfig.node.json           # Node 侧 TS 配置（vite.config.ts）
├─ src/
│  ├─ api/          # axios 实例(request.ts) + 各模块接口(auth/user/role/menu/dept/dict/config/log/file/gen/dashboard/profile)
│  ├─ assets/       # 静态资源
│  ├─ components/   # 通用组件：BasicDialog / ErrorPage / IconPicker / MenuTree / Pagination / SearchForm / VditorEditor
│  ├─ composables/  # 组合式复用逻辑（useTable / useTheme / useResponsiveSize / useDict）
│  ├─ directives/   # v-permission 按钮权限指令及注册
│  ├─ layout/       # 主布局（AppMain / Navbar / Sidebar / TagsView）
│  ├─ router/       # 路由实例 / 静态路由表 / 全局守卫
│  ├─ store/        # Pinia（index.ts + modules/{app,user,permission,tagsView}.ts）
│  ├─ styles/       # index.css（Tailwind v4 入口 + @theme 令牌 + base 重置）/ element.scss（EP 覆盖）
│  ├─ types/        # 全局类型 / 接口 DTO / 路由 meta
│  ├─ utils/        # auth / format / permission / validate / element(命令式 API 桶) 等
│  ├─ views/        # 页面：home / login / upload / system / log / profile / tool / error / redirect
│  ├─ App.vue       # 根组件
│  └─ main.ts       # 入口：样式引入顺序、注册 Pinia/Router/指令
```

## 后端 `api/src` 关键目录

```
api/src/
├─ config/       # index.ts（读取 .env）/ database.ts（Sequelize 实例 + sync）
├─ controllers/  # 控制器：参数解析 + 调 Service + 组装响应
├─ middlewares/  # auth / permission / validate / errorHandler / operationLog / upload ...
├─ models/       # Sequelize 模型 + 关联
├─ routes/       # 业务路由 + index.ts 聚合（统一挂在 /api）
├─ seed/         # 种子数据
├─ services/     # 业务逻辑（唯一操作 Model 的层）
├─ logging/      # 日志子系统
├─ docs/         # 运行时 /api-docs 文档源码（禁止误删）
├─ validators/   # zod 校验 schema
├─ app.ts        # 创建 Express、挂载中间件 / 静态 / 路由 / 错误处理
└─ server.ts     # 入口
```

## 目录职责约定（前端）

| 目录              | 职责                | 说明                                                                                                   |
| ----------------- | ------------------- | ------------------------------------------------------------------------------------------------------ |
| `src/views`       | 路由级页面          | 一个路由一个 `.vue`，页面专属组件放页面同名子目录                                                      |
| `src/components`  | 跨页面复用组件      | 业务无关，可配置化优先                                                                                 |
| `src/composables` | 组合式函数（Hooks） | 跨组件复用的响应式逻辑，统一 `useXxx` 命名                                                             |
| `src/store`       | Pinia store         | 按领域拆分 `modules/*.ts`，一律 Setup Store                                                            |
| `src/api`         | 接口层              | `request.ts` 封装 axios，其余按模块拆分接口函数                                                        |
| `src/utils`       | 纯函数 / 桶文件     | 不含组件、不含副作用；`element.ts` 为命令式 API 桶                                                     |
| `src/types`       | 类型声明            | 全局类型 / DTO / 路由 meta                                                                             |
| `src/styles`      | 全局样式            | `index.css`（Tailwind v4 拆分导入 + `@theme` 令牌 + base 重置）、`element.scss`（EP 覆盖，带命名空间） |

## 最佳实践

- 别名统一用 `@`：指向 `src`，与 `tsconfig.json` 的 `paths` 和 `vite.config.ts` 的 `alias` 三端对齐。
- `auto-imports.d.ts` / `components.d.ts` 由插件生成，**提交入库但评审时跳过**；`eslint.config.mjs` 已显式忽略这两文件。
- `package-lock.json` 必须提交入库；`dist/`、`node_modules/`、`api/uploads/`、`api/logs/`、`api/web/` 等产物/内容一律 gitignore。
