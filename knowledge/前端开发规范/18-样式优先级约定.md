# 18 - 样式优先级约定

本项目样式按以下优先级选用，**禁止随意混用**（与 10-TailwindCSS使用.md 互为补充）。

## 优先级

### 1. Tailwind CSS（首选）

布局、间距、排版、颜色、响应式、伪类等**一切 Tailwind 工具类能实现的效果**，一律使用 Tailwind 类名，不允许额外编写 SCSS/CSS。

- 语义色已映射到 Tailwind（见 10）：`text-primary` / `bg-surface` / `text-ink` / `border-line` 等，自动适配亮/暗主题，令牌定义在 `index.css` 的 `@theme`。
- 阴影用 `shadow-el-light`（映射到 `--el-box-shadow-light`），勿写 `shadow-[var(--el-...)]`。

### 2. SCSS（降级兜底）

当效果**确实无法**用 Tailwind 工具类实现时（如复杂 `@keyframes` 动画、动态 `calc()` 混合单位、CSS 多边形裁剪），才使用 SCSS，且**必须写在 SFC 的 `<style scoped lang="scss">`**，避免全局污染。

### 3. 判断标准

写样式前先问：这个效果能否用 `class=""` 完成？能，则不应写任何 SCSS。有争议时以 Tailwind 官方文档能查到的工具类为准。

### 4. 全局样式与 Element Plus 覆盖（例外）

以下全局样式是约定的**唯一例外**，不在 SFC 内写：

- `src/styles/index.css`：Tailwind v4 拆分导入（省略 preflight）+ `@theme` 设计令牌 + `@layer base` 必要重置（border / box-sizing / body / img 等）。**不要删** base 里的 border 重置。
- `src/styles/element.scss`：Element Plus 覆盖，**仅做带命名空间的覆盖**，不使用 `!important` 强行改写组件内部外观。已落地的命名空间钩子类（**不可删**）：
  - `.sidebar`：侧边栏菜单项高亮、二级菜单面板、折叠宽度。
  - `.el-table.el-table`：表头浅底加粗、悬停主色浅蓝、行距、柔化边框。
  - `.table-action`：操作列按钮间距。
  - `.search-form`：搜索表单区域卡片化。
  - `.flex-center`：全局工具类（居中）。

## 实操对照

| 场景                      | ✅ 正确做法                                           | ❌ 错误做法                                                  |
| ------------------------- | ----------------------------------------------------- | ------------------------------------------------------------ |
| 两栏布局                  | `flex justify-between`                                | SCSS `.c { display: flex; justify-content: space-between; }` |
| 响应式间距                | `p-4 md:p-6`                                          | SCSS `@media` 断点 + padding                                 |
| 文字主题色                | `text-primary` / `text-[#1890ff]`                     | SCSS 变量 + color                                            |
| 复杂 `@keyframes` 动画    | SCSS SFC scoped                                       | 硬写在全局 SCSS                                              |
| 动态 `calc()` 混合单位    | SCSS SFC scoped                                       | 放弃 Tailwind 变体                                           |
| Element Plus 组件样式覆盖 | Element Plus 变量 / `.el-table.el-table` 命名空间覆盖 | Tailwind 类名强行 override                                   |
| 阴影                      | `shadow-el-light`                                     | `shadow-[var(--el-box-shadow-light)]`                        |

## 设计原则

- 业务组件样式优先用 Tailwind；组件库内部样式交给 Element Plus，不混用 Tailwind 覆盖其内部类。
- 全局覆盖一律带命名空间（如 `.sidebar`），避免污染其它 `el-menu` / `el-table`。
- 暗黑主题由 `html.dark` + Element Plus 变量 + Tailwind 语义色映射统一驱动，不要在样式里写死颜色字面量（亮暗会失配）。
