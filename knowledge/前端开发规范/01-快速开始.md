# 01 - 快速开始

## 1. 环境准备

| 项      | 要求      | 说明                                                                                    |
| ------- | --------- | --------------------------------------------------------------------------------------- |
| Node.js | >= 24.0.0 | `package.json` 的 `engines` 已声明（即 24+）；当前开发机为 24.x，CI/部署需满足 >=24.0.0 |
| npm     | >= 10     | 包管理器唯一，禁止 pnpm / yarn 混用                                                     |
| MySQL   | 8.x       | 需提前创建数据库 `ly_admin`（utf8mb4）                                                  |
| Redis   | 可选      | 图形验证码共享、登录限流、登出黑名单；留空 `REDIS_HOST` 即降级                          |

> **镜像源**：根目录 `.npmrc` 已配置 `registry=https://registry.npmmirror.com`，`npm install` 走国内镜像，无需手动切换。

## 2. 安装依赖

本仓库是 monorepo，**根依赖（工程规范 + husky 钩子）务必先装**，否则提交钩子不生效：

```bash
npm install                        # 根目录：装配 husky + 安装 eslint/prettier/stylelint/commitlint
cd ly-admin-api && npm install     # 后端（NestJS 12 + Prisma 7）
cd ../ly-admin-web && npm install  # 前端（Vue 3.5 + Vite 8）
```

## 3. 配置并启动

```bash
# 后端环境变量（首次需复制模板）
cd ly-admin-api && cp .env.example .env
# 至少填 DB_* 与 JWT_ACCESS_SECRET / JWT_REFRESH_SECRET（必填且互不相同）

# 首次还需建表并同步表/字段注释
# （Prisma 7 不在服务启动时建表；注释由 schema 的 /// 生成，见 README 第 4 步）
npm run prisma:push
npm run prisma:comments

# 根目录：有序启动前后端（后端 :3000，前端 :5173）
# scripts/dev.mjs 会等后端健康检查返回 200 后才拉起 vite，
# 避免「前端先起、首屏请求打到还没监听的 :3000」；已有后端在跑则自动复用
npm run dev
```

> 种子数据在服务启动时**幂等**执行，无需手动跑；也可用 `npm run seed` 单独执行。

或分别启动：

```bash
cd ly-admin-api && npm run start:dev   # http://localhost:3000
cd ly-admin-web && npm run dev         # http://localhost:5173
```

启动后访问：

- 前端页面：<http://localhost:5173>
- 健康检查：`GET http://localhost:3000/api`

> 前端 dev server 通过 Vite 代理把 `/api`、`/static` 转发到 `http://localhost:3000`，开发期同源、无跨域。

## 4. 常用命令

| 命令                   | 说明                                         |
| ---------------------- | -------------------------------------------- |
| `npm run dev`          | 有序启动前后端（后端就绪后才启动前端）       |
| `npm run dev:api`      | 仅启动后端                                   |
| `npm run dev:web`      | 仅启动前端                                   |
| `npm run lint`         | 全仓 ESLint 检查（`--max-warnings 0`）       |
| `npm run lint:fix`     | 全仓 ESLint 自动修复                         |
| `npm run format`       | 全仓 Prettier 格式化                         |
| `npm run format:check` | 全仓 Prettier 格式校验（不写文件）           |
| `npm run stylelint`    | 全仓 Stylelint 检查                          |
| `npm run guard:deps`   | 校验三处 `package.json` 运行时依赖与基线一致 |
| `npm run commit`       | cz-git 交互式生成规范提交                    |

前端 `ly-admin-web/` 与后端 `ly-admin-api/` 另有各自的 `build` / `typecheck` / `seed` / `prisma:*` 等脚本，见 `README.md`。

## 5. 常见错误

| 错误                   | 原因                                                         | 解决                                                                                     |
| ---------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 提交时钩子不执行       | 只在 `ly-admin-web/` 或 `ly-admin-api/` 装依赖，根钩子未装配 | 在**根目录** `npm install`（触发 `prepare` → `husky`）                                   |
| 启动即报 JWT 相关错误  | `JWT_ACCESS_SECRET` / `JWT_REFRESH_SECRET` 缺失或相同        | 生成随机值填入 `ly-admin-api/.env`（见 README 第 3 步）                                  |
| 数据库连不上           | MySQL 未启动 / `ly_admin` 库未创建                           | 创建库并核对 `DB_*`                                                                      |
| 报缺表 / Unknown table | 未执行建表（Prisma 7 不在启动时建表）                        | `cd ly-admin-api && npm run prisma:push`                                                 |
| 端口被占用             | `vite.config.ts` 为 `strictPort: true`                       | 改 `ly-admin-api/.env` 的 `PORT` 与 `vite.config.ts` 的 proxy `target`，以及 `VITE_PORT` |
