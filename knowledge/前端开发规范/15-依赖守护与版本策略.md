# 15 - 依赖守护与版本策略

## 1. 零第三方运行时依赖（硬约束）

本仓库把「零第三方运行时依赖」作为**项目身份约束**，由 `scripts/deps-guard.mjs`（零依赖哨兵）守护：

- 校验对象：根 / `ly-admin-api` / `ly-admin-web` 三处 `package.json`。
- 基线文件：`scripts/deps-baseline.json`（与脚本同目录）。
- 规则：
  - `dependencies`（运行时依赖）新增 / 移除 / 版本变更 → **校验失败（退出码 1）**，逐条列出哪个包、哪处 package.json。
  - `devDependencies` 变化 → **仅告警**（退出码 0），因为测试/工具类依赖不破坏运行时零依赖约束。
- 触发点：`pre-push` 钩子执行 `npm run guard:deps`，推送前必过。

```bash
npm run guard:deps                 # 校验三处 package.json 依赖是否偏离基线
npm run guard:deps -- --update     # 显式更新基线（scripts/deps-baseline.json）
```

> **新增运行时依赖是特例，不是常态**。确需引入时：先评估能否用现有依赖（如 `lodash-es` / `@vueuse/core`）替代；若必须新增，显式运行 `--update` 更新基线，并在 PR 评审中说明原因。切勿静默 `npm i <pkg>` 后直接推送（会被 pre-push 拦截）。

## 2. 包管理器与版本策略

- **包管理器统一 npm**（>= 10），禁止 pnpm / yarn 混用。
- 依赖用 `^` 范围（如 `"vue": "^3.5.43"`），不写死精确版本；允许 npm 在范围内取最新补丁/次版本。
- `package-lock.json`（根 + `ly-admin-api/` + `ly-admin-web/`）**必须提交入库**，禁止 gitignore，用于锁定实际解析结果、保证团队安装一致。
- **例外条款**：仅在遇到依赖版本冲突、插件不兼容时，允许锁定旧版本，且必须在代码注释或 PR 中注明锁定原因；问题解决后恢复 `^` 范围。

## 3. 镜像源

根 `.npmrc` 已配置 `registry=https://registry.npmmirror.com`，团队安装走国内镜像，无需手动切换。新成员勿覆盖此文件。

## 4. 版本发布

发版相关的分支、tag 与 CHANGELOG 约定属于仓库级规则，见 [`Git 提交规范/02-分支与发布`](../Git提交规范/02-分支与发布.md)。本节只强调与依赖相关的部分：发布流程如需引入 release-it / standard-version 等工具，应装在 `devDependencies`（`devDependencies` 变化不触发 `guard:deps` 失败，但仍需在 PR 说明）。

## 5. 常见错误

| 现象                                     | 原因                            | 解决                                                                     |
| ---------------------------------------- | ------------------------------- | ------------------------------------------------------------------------ |
| push 被 pre-push 拦截：dependencies 变更 | 新增/升级了运行时依赖未更新基线 | 评估必要性；确需则 `npm run guard:deps -- --update` 并更新基线，评审说明 |
| 团队协作依赖不一致                       | package-lock.json 未提交        | 确保 lockfile 已 commit，勿 gitignore                                    |
| 安装缓慢/超时                            | 未走镜像                        | 确认根 `.npmrc` 指向 npmmirror                                           |
