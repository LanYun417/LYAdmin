# 03 - 环境要求

## 1. Node 引擎与包管理器

```json
// package.json（根）
{
  "engines": { "node": ">=20.19.0" }
}
```

- **Node**：声明 `>=20.19.0`，当前开发机为 **24.x**。本仓库**不**要求固定 Node 24，CI/部署满足 `>=20.19.0` 即可（与通用模板"Node 24 固定"不同）。
- **包管理器**：统一 **npm**（>= 10）。禁止 pnpm / yarn 混用；依赖用 `^` 范围，不写死精确版本。
- **镜像**：根 `.npmrc` 已配置 `registry=https://registry.npmmirror.com`，无需手动切换。
- **锁定文件**：`package-lock.json`（根 + `admin/`）必须提交入库，禁止 gitignore，用于锁定实际解析结果、保证团队安装一致。

## 2. Node 对 TypeScript 的原生支持（知悉即可）

Node 22+ 已支持 Type Stripping（类型剥离），可直接 `node file.ts`。但本项目**仍依赖编译/类型检查**：

- 类型剥离 ≠ 类型检查：Node 只擦除类型注解再执行，不做任何类型校验。
- 类型检查由 `vue-tsc`（`admin`）/ `tsc`（`api`）负责。
- Vue SFC 的 `<script setup lang="ts">` 仍由 Vite 编译处理，不会直接交给 Node 执行。
- 构建脚本（如 `scripts/deps-guard.mjs`）使用 Node 内置模块零依赖实现，不依赖 ts-node/tsx。

## 3. Vite 版本

- 本仓库**已采用 Vite 8**（底层 Rolldown，Rust 实现）。`admin/package.json` 中 `vite: "^8.3.0"`。
- 自动导入插件均已验证兼容 Vite 8：`unplugin-auto-import@^21`、`unplugin-vue-components@^32`、`@vitejs/plugin-vue@^6`。
- 构建期预压缩由 `vite-plugin-compression2` 完成（同时产出 .gz 与 .br）。
- 第三方大库通过 `build.rollupOptions.output.manualChunks` 拆成 `echarts` / `vditor` / `element-plus` / `vue-vendor` / `vendor` 独立 chunk，提升长缓存命中。

## 4. 依赖策略

- 运行时依赖（`dependencies`）受 `scripts/deps-guard.mjs` 守护：**默认零新增第三方运行时依赖**（见 16-依赖守护）。
- 开发依赖（`devDependencies`）变化仅告警，不阻断。
- `admin` 现有运行时依赖：`vue` / `vue-router` / `pinia` / `@vueuse/core` / `axios` / `element-plus` / `echarts` / `vditor` / `dayjs` / `lodash-es` / `nprogress` / `bootstrap-icons-vue` / `pinia-plugin-persistedstate`。

## 5. 常见错误

| 错误                                 | 解决                                                                  |
| ------------------------------------ | --------------------------------------------------------------------- |
| `npm install` 提示引擎不满足         | 确认 Node >= 20.19.0；`node -v` 核对版本                              |
| 安装缓慢或超时                       | 确认根 `.npmrc` 指向 npmmirror；公司网络按需在 `.npmrc` 追加配置      |
| 直接 `node script.ts` 报类型语法错误 | 本项目脚本零依赖 Node 原生实现；若确需跑 TS 脚本，走 `tsx` 或编译产物 |
