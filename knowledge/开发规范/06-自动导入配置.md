# 06 - 自动导入配置（核心）

> 本仓库自动导入策略与通用模板**有本质差异**，请先读本节再写代码。

## 覆盖范围

| 来源                        | 自动导入内容                 | 示例                                            | 配置方式                                   |
| --------------------------- | ---------------------------- | ----------------------------------------------- | ------------------------------------------ |
| Vue                         | 组合式 API                   | `ref` `computed` `watch` `onMounted` `reactive` | `AutoImport`                               |
| Vue Router                  | 路由 API                     | `useRoute` `useRouter`                          | `AutoImport`                               |
| Pinia                       | store API                    | `defineStore` `storeToRefs`                     | `AutoImport`                               |
| VueUse                      | 组合函数                     | `useDark` `useStorage` `useWindowSize`          | `AutoImport`                               |
| Element Plus 组件           | 模板内组件                   | `<el-button>` `<el-form>` `<el-input>`          | `Components` + `ElementPlusResolver`       |
| 项目自有组件                | `src/components` 下组件      | `<BasicDialog>` `<Pagination>`                  | `Components`（`dirs: ['src/components']`） |
| **Element Plus 命令式 API** | **ElMessage / ElMessageBox** | `ElMessage.success(...)`                        | **不自动导入**，见下文桶文件               |

## 关键差异：Element Plus 命令式 API 走桶文件

通用模板通常把 `ElMessage` / `ElMessageBox` 交给 `AutoImport` 自动导入。本项目**有意不这样做**，因为在 `utils/element.ts` 中改从子路径引入并显式加载样式，可避免从包根 `import { ElMessage } from 'element-plus'` 触发整库打包（约 284 kB 原始 / 90 kB gzip 被拖进首屏）。

```ts
// src/utils/element.ts
export { default as ElMessage } from 'element-plus/es/components/message/index';
export { default as ElMessageBox } from 'element-plus/es/components/message-box/index';

import 'element-plus/es/components/message/style/css';
import 'element-plus/es/components/message-box/style/css';
```

**使用方式（必须）：**

```ts
// ✅ 正确：从桶文件引入
import { ElMessage } from '@/utils/element';
ElMessage.success('保存成功');

// ❌ 错误：整库引入（拖慢首屏，违反零依赖优化初衷）
import { ElMessage } from 'element-plus';

// ❌ 错误：手动 import 已自动导入的组件（重复）
import { ElButton } from 'element-plus';
```

> 若后续用到 `ElNotification` / `ElLoading` 等，按相同模式在 `utils/element.ts` 补导出与样式即可。

## 配置（vite.config.ts）

```ts
AutoImport({
  imports: ['vue', 'vue-router', 'pinia', '@vueuse/core'],
  resolvers: [ElementPlusResolver()],
  dts: 'auto-imports.d.ts', // 生成在 admin/ 根
  eslintrc: { enabled: false }, // 不生成 .eslintrc-auto-import.json
});

Components({
  resolvers: [ElementPlusResolver()],
  dirs: ['src/components'], // 项目组件也自动注册
  extensions: ['vue'],
  deep: true,
  dts: 'components.d.ts', // 生成在 admin/ 根
});
```

## d.ts 落点与 ESLint 适配

- 生成文件：`admin/auto-imports.d.ts`、`admin/components.d.ts`（**在 `admin/` 根，非 `src/types`**）。
- 这两文件被 `tsconfig.json` 的 `include` 收编，TypeScript 由此认识自动导入的标识符。
- 文件由插件在 dev 启动时自动重写，**不要手动编辑**；仓库中已预置，首次 type-check 可通过。
- `eslintrc.enabled: false` → **不生成** `.eslintrc-auto-import.json`。ESLint 端通过 `eslint.config.mjs` 中 TS 文件 `no-undef: 'off'` + 显式浏览器全局来规避 `no-undef`，而非读入 auto-import globals（见 13）。
- `eslint.config.mjs` 已显式 `ignores` 这两个 d.ts，避免它们被 lint。

## 手动 import 的合法例外

1. 入口装配：`main.ts` 的 `createApp/createPinia`、`router/index.ts` 的 `createRouter`。
2. 资源文件：Element Plus 语言包 `element-plus/es/locale/lang/zh-cn`、暗黑变量 `element-plus/theme-chalk/dark/css-vars.css`。
3. 项目自有模块：`@/store/*`、`@/utils/*`、`@/api/*`、`@/composables/*`。
4. **Element Plus 命令式 API**：必须从 `@/utils/element` 引入（见上）。

## 常见错误

| 现象                                  | 原因                         | 解决                                                |
| ------------------------------------- | ---------------------------- | --------------------------------------------------- |
| 运行时 `ref is not defined`           | 插件未生效                   | 检查 `vite.config.ts` 插件注册；重启 dev            |
| TS 报 `Cannot find name 'ref'`        | d.ts 缺失/未 include         | `npm run dev` 一次生成；检查 tsconfig `include`     |
| `ElMessage` 样式异常 / 整库被打进首屏 | 从 `'element-plus'` 整库引入 | 改为从 `@/utils/element` 引入                       |
| ESLint 报 `no-undef`                  | TS 文件的 no-undef 不应开启  | 由 `eslint.config.mjs` 统一关掉（勿手动加 globals） |
