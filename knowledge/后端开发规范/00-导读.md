# 00 - 导读

LYAdmin 后端开发规范。本文档面向接手 `ly-admin-api/` 的开发者，基于仓库中的**真实代码与配置**编写，与 [`前端开发规范`](../前端开发规范/00-导读.md)、[`Git 提交规范`](../Git提交规范/00-导读.md)、`README.md` 互为补充。

## 技术栈

| 层       | 技术                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 运行时   | Node.js >= 24，纯 ESM（`"type": "module"`）                                          |
| 框架     | NestJS 12（Express 5 适配层）                                                        |
| 语言     | TypeScript 6（`nodenext`，严格模式）                                                 |
| 数据层   | Prisma 7.10 + `@prisma/adapter-mariadb`（运行期 driver adapter）+ MySQL 8            |
| 校验     | class-validator + class-transformer（全局 ValidationPipe，whitelist + transform）    |
| 鉴权     | jose（JWT 双 Token）+ @node-rs/bcrypt（口令）+ Redis（可选：验证码 / 黑名单 / 限流） |
| 上传     | multer（磁盘存储）+ sharp（图片缩放）+ 幻数校验                                      |
| 测试     | vitest（单测）+ supertest（e2e，真实 MySQL / Redis）                                 |
| 代码质量 | oxlint（type-aware）+ Prettier + `tsc --noEmit`                                      |

## 硬性约定（违反即不通过 Code Review / 门禁）

- **纯 ESM**：相对导入一律带 `.js` 后缀（如 `import { config } from './config.js'`），不写扩展名会在 Node ESM 下解析失败。
- **单一配置入口**：只有 `src/common/config.ts` 读取 `process.env`，其它模块一律 `import { config }`。
- **分层边界**：`module → controller → service`；controller 不访问 `PrismaService`，service 不读写 `Request/Response`。
- **DTO 必须可校验**：请求体 / 路径参数一律用 class-validator 装饰过的 DTO；**没有任何装饰器的 DTO 会被 `whitelist` 清空所有字段**（详见 08）。
- **统一响应**：成功响应恒为 HTTP 200，响应体 `{ code, message, data }`；错误统一抛 `AppException`，不手写 `res.json()`。
- **权限声明**：需要权限码的接口必须加 `@RequirePermissions(...)`；公开接口用 `@Public()`；两者都不加表示「登录即可访问」。
- **写操作留痕**：POST / PUT / PATCH / DELETE 端点加 `@OperationLog('模块', '动作')`（认证类除外）。
- **接口文档自动生成**：`GET /api/docs` 的清单由 `npm run build`（prebuild → `docs:gen`）扫描控制器生成，勿手改 `src/modules/docs/api-docs.generated.ts`（详见 14）。
- **schema 注释即文档**：表 / 字段说明只写在 `prisma/schema/*.prisma` 的 `///` 里，改完执行 `npm run prisma:comments`。
- **依赖最小化**：运行时依赖变更必须显式更新 `scripts/deps-baseline.json`（`npm run guard:deps -- --update`）并在评审说明。
- **提交前全绿**：`typecheck` / `lint` / `test` / `build` / `prisma validate` 缺一不可（见 12）。

## 五分钟自检

```bash
cd ly-admin-api
npm run typecheck        # tsc --noEmit --incremental false
npm run lint             # oxlint --type-aware（0 error / 0 warning）
npm run test             # vitest 单测
npm run test:e2e         # 契约 + 冒烟（需 MySQL / Redis）
npm run build            # nest build
npx prisma validate      # schema 合法性
```
