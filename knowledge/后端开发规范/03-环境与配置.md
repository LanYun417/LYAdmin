# 03 - 环境与配置

## 1. 唯一入口

`src/common/config/config.ts` 是**全项目唯一**读取 `process.env` 的地方：

- 业务代码一律 `import { config } from '../../common/config/config.js'`，不要在模块里直接读环境变量。
- 启动时先加载 `ly-admin-api/.env`，**已存在的环境变量优先**（便于容器 / 命令行覆盖）。
- `.env` 采用 `KEY=VALUE`，支持成对引号；不引入 dotenv，保持零运行时依赖。

```ts
// ✅
const limit = config.upload.maxSize;
// ❌
const limit = Number(process.env.UPLOAD_MAX_SIZE);
```

## 2. fail-fast 规则

配置错误一律在**启动时**暴露，不允许带病运行：

| 场景                                                  | 行为                                                 |
| ----------------------------------------------------- | ---------------------------------------------------- |
| `JWT_ACCESS_SECRET` / `JWT_REFRESH_SECRET` 缺失或为空 | 抛错，服务拒绝启动                                   |
| 两个 JWT 密钥相同                                     | 抛错，服务拒绝启动（防止 Token 混用）                |
| 日志保留天数 ≤ 0 / 非整数 / 非数字                    | 回退默认值并打印告警（`retention = 0` 会删光日志表） |
| Redis 未配置                                          | 视为「不启用」，相关增强降级，不阻塞主流程           |
| 上传目录 / 日志目录不存在                             | 启动时自动创建                                       |

## 3. 配置分组

| 分组           | 关键项                                                                                | 说明                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `env` / `port` | `NODE_ENV` / `PORT`                                                                   | 端口默认 3000                                                                                                          |
| `trustProxy`   | `TRUST_PROXY`                                                                         | 默认 0，不信任 `X-Forwarded-For`（防伪造 IP）                                                                          |
| `db`           | `DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USER` / `DB_PASSWORD` / `DB_CONNECTION_LIMIT` | 连接池上限默认 10（1~100）；`DATABASE_URL` 仅 CLI 使用                                                                 |
| `jwt`          | 两个密钥 + 有效期（默认 access 2h / refresh 7d）                                      | 密钥无默认值                                                                                                           |
| `captcha`      | `CAPTCHA_ENABLED` / `CAPTCHA_TTL_MS` / `CAPTCHA_LENGTH`                               | 默认开启，5 分钟、4 位                                                                                                 |
| `upload`       | 目录、路由前缀、缓存目录、大小 / 数量上限、Referer 白名单、`UPLOAD_USER_QUOTA_MB`     | 缓存目录必须在静态根之外；配额默认 512MB，0 = 不限                                                                     |
| `web`          | `WEB_DIST_DIR`                                                                        | 同源部署时托管前端产物                                                                                                 |
| `redis`        | `REDIS_HOST` / `REDIS_PORT` / `REDIS_PASSWORD` / `REDIS_DB`                           | `REDIS_HOST` 为空即不启用                                                                                              |
| `corsOrigin`   | `CORS_ORIGIN`                                                                         | 逗号分隔多个来源                                                                                                       |
| `log`          | 目录、归档目录 / 时刻（`LOG_ARCHIVE_DIR`）、慢 SQL 阈值、三类日志保留天数             | 归档 00:05、清理 00:10，刻意错开                                                                                       |
| `security`     | `CSP_POLICY` / `SECURITY_HSTS`                                                        | CSP 默认空 = 不下发；HSTS 默认跟随 production                                                                          |
| `ip2region`    | `IP2REGION_DB_PATH`                                                                   | 默认 `data/ip2region_v4.xdb`（约 10MB，不入库）；缺失降级为空                                                          |
| `monitor`      | `NET_DEV_PATH`                                                                        | 网卡计数文件路径覆盖：默认 Linux 读 `/proc/net/dev`；用于非 Linux 集成测试，或 host 网络命名空间下指向挂载的宿主机文件 |
| `version`      | `APP_VERSION` / `GIT_COMMIT`                                                          | 出现在 `/api` 与 `/api/health/live`，由构建 / CI 注入                                                                  |
| `rateLimit`    | `RATE_LIMIT_ENABLED` / `RATE_LIMIT_WINDOW_MS` / `RATE_LIMIT_MAX`                      | 默认开启，60s / 300 次（按 IP）                                                                                        |
| `password`     | `PASSWORD_MIN_LENGTH` / `PASSWORD_MAX_LENGTH` / `PASSWORD_REQUIRE_COMPLEXITY`         | 默认 8~20 位且需字母+数字；种子口令用 `SEED_ADMIN_PASSWORD`                                                            |
| `export`       | `EXPORT_MAX_ROWS` / `EXPORT_BATCH_SIZE`                                               | 单次导出上限 5 万行；分批 1000（0 = 不限制，不建议）                                                                   |

类型转换统一走 `toNumber` / `toBoolean` / `parseRetentionDays`：空串与非法值回退默认值，
**绝不**把 `''` 静默当成 `0`。

## 4. 应用装配

`src/app.setup.ts` 的 `configureApp()` 被 `main.ts` 与 e2e 共用，保证「跑的装配」与「测的装配」一致：

| 配置           | 值 / 行为                                                                               |
| -------------- | --------------------------------------------------------------------------------------- |
| 全局前缀       | `api`（前端 baseURL `/api`）                                                            |
| 适配器         | `OkExpressAdapter`：成功响应恒 HTTP 200                                                 |
| 请求体上限     | JSON / urlencoded 均 2MB                                                                |
| 校验管道       | `whitelist: true`、`transform: true`、`enableImplicitConversion`                        |
| CORS           | `CORS_ORIGIN` 为 `*` 时反射来源，否则按逗号白名单                                       |
| `x-powered-by` | 关闭                                                                                    |
| 安全响应头     | `nosniff` / `SAMEORIGIN` / `Referrer-Policy` / `Permissions-Policy`（+ 可选 HSTS、CSP） |
| 接口限流       | 按 IP 固定窗口（Redis `INCR`），Redis 不可用降级放行；健康检查不计入                    |
| `etag`         | 关闭（避免动态响应产生 304）                                                            |
| 响应压缩       | >1KB 的 JSON / JS / CSS / SVG 按 `Accept-Encoding` 输出 br / gzip                       |
| 静态缓存       | 构建产物 `1y + immutable`、上传文件 `30d + immutable`                                   |
| 预压缩静态     | 优先发送构建期 `.br` / `.gz`，未命中再回落原文件                                        |
| 静态资源       | `serveStatic: true` 时才挂载 uploads 与前端产物                                         |
| history 回退   | 仅接管 `Accept: text/html` 的 GET/HEAD，其余交还路由                                    |

> 新增全局配置（管道、拦截器、前缀、CORS 等）必须写进 `configureApp`，不要在 `main.ts` 里单独加，
> 否则 e2e 实例与生产实例会分叉。

## 5. 部署相关

- **一键部署见 `deploy/`**：`Dockerfile`（多阶段：web 构建 → api 构建 → 生产运行时）、
  `docker-compose.yml`（mysql + redis + 一次性 migrate + api）、`nginx.conf`（反代示例）、
  `README.md`（步骤、环境变量清单、备份、限制）。前端产物由 api 同源托管，也可交给 nginx。
- 容器编排的探针用 `GET /api/health/live`（liveness，不碰依赖）与 `GET /api/health/ready`
  （readiness，探 DB/Redis，DB 不可用返回 503）；`GET /api` 是兼容用的根探活。
- 反向代理后部署时设置 `TRUST_PROXY=1`，否则限流与审计日志拿到的是代理 IP。
- 生产环境用 `NODE_ENV=production`，`UPLOAD_DIR` / `LOG_DIR` / `cache` 必须可写且持久化。
- 同源部署把前端产物构建到 `ly-admin-api/web/`（或 `WEB_DIST_DIR` 指向的目录），后端会自动托管并做 history 回退。
- `CORS_ORIGIN` 与 `UPLOAD_ALLOWED_REFERERS` 在分离部署时必须显式配置，否则分别出现跨域失败与静态资源 403。
- 安全响应头默认下发 `nosniff` / `X-Frame-Options: SAMEORIGIN` / `Referrer-Policy` / `Permissions-Policy`；
  `Strict-Transport-Security` 仅在 `SECURITY_HSTS`（默认 production）时下发，**CSP 默认不下发**——
  前端是 SPA，Element Plus / Tailwind 会写内联样式、ECharts 用 canvas，过严策略会直接白屏，
  需要时用 `CSP_POLICY` 显式配置。
- 限流阈值（单 IP / 单窗口）：登录 20、验证码 30、接口文档 120、其余 `RATE_LIMIT_MAX`（默认 300）。
  `/api/health/*` 与 `GET /api` 不计入（探针高频，计入就会把自己打成 429）。
- 口令策略只在**新设置口令**时生效（新增用户 / 重置密码 / 自助改密，统一在
  `common/auth/password-policy.ts`），存量账号登录不受影响；「不得与账号互相包含」是跨字段规则，
  由服务层断言而非装饰器。种子超管口令来自 `SEED_ADMIN_PASSWORD`，未配置时用开发默认口令并在
  production 打 warn —— **生产首次部署务必配置该变量或登录后立即改密**。
