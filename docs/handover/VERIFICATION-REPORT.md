1. **权限码隐性耦合**：`system:user:assignRole` 与 `system:role:all` **今后必须成对授予**。当前 admin 两个都有所以无问题，但将来新建角色若只给前者，「分配角色」下拉框会空。建议写进权限规范。
2. **限流的兜底定位**：应用层这套是**单机内存**方案，进程重启即失效、多实例不共享；真实生产建议在反向代理层（nginx `limit_req`）做。
3. **撞库防护已补但仍有限**：IP 维度阈值 20 次/5 分钟，对共享出口 IP（办公室/校园）会放宽命中。若将来部署在 NAT 密集环境，阈值需重新评估。
