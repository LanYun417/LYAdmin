## 8. 发现与遗留风险

| 级别 | 项                       | 说明                                                                                                                                               | 建议                                                                                                                            |
| ---- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 低   | `login()` 未失效鉴权缓存 | 登录会 `update(lastLoginAt)`，但缓存条目未失效；同一用户 30s 内已有缓存时，`/auth/profile` 的 `lastLoginAt` 可能短暂陈旧（仅展示字段，无安全影响） | 可在 `login()` 成功后 `invalidateAuthCache(user.id)`，或将 `lastLoginAt` 移出缓存字段                                           |
| 低   | B4 SIGKILL 丢尾部日志    | 命令行 `SIGKILL`/断电时，缓冲区内未落盘 SQL 日志（≤100ms / ≤200 条）会丢失                                                                         | **可接受**：`logs/db/` 为调试/性能日志，非审计源；审计用的 `sys_http_log` 走 DB 同步写入，不受影响。若追求极致可缩短 flush 间隔 |
| 信息 | `/api/logs/http` 无提升  | 受 `sys_http_log` 表增长影响，属数据规模问题，非优化回退                                                                                           | 大表建议为 `time` 加索引 / 用近似计数                                                                                           |
| 信息 | F2 未达 ≤500 kB          | echarts 已按需但仍 565 kB raw / ~190 kB gzip                                                                                                       | 可评估进一步裁剪组件或改按路由异步加载                                                                                          |
| 提示 | 单次采样噪声大           | 8GB 同机，对照组 RPS 波动达 ~77%                                                                                                                   | 结论以区间与方向为准；如需精确对比应多轮取中位数                                                                                |
